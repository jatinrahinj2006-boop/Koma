### 📖 About Koma

Reading multi-chapter manhwa strips or manga volumes online? Instead of manually saving thousands of individual image files page-by-page, **Koma** automates chapter detection, lazy-loaded vertical scrolling, parallel background scraping, and clean `.zip` / `.pdf` packaging with one click.

### ✨ Key Features

- ⚡ **1-Click Chapter Extraction**: Auto-triggers lazy-loaded comic strips and downloads high-res images in sequence.
- 📚 **Batch Chapter Ranges**: Queue multiple chapters (e.g., Chapters 1–50) with automated background URL navigation.
- 📦 **Clean Packaging**: Automatically bundles chapters into structured subfolders or organized `.zip` files.
- 📱 **Chrome Side Panel**: Inspect and review chapter pages directly inside Chrome's native side panel before saving.
- 🛠️ **PDF Studio Compiler**: Compile raw image archives into readable offline PDF volumes with duplicate detection.
- 🛡️ **Paced & Safe**: Isolated network rules and TCP socket throttling to prevent IP rate-limiting and browser lag.
